## Example

What the file should contain, and the acceptance criteria that say when it is done.

## Location

**Git/Issues**, in the [location key](../grid.md#location-key).

## Clear when

A few observable, binary criteria and a verification command, bounded in scope, with no blocker open; whoever accepted them is named.

## Excess

- **A criterion that describes the implementation.** The criterion says what is observed when it is done, not how. How is the diff's. Test: ask whether the criterion names what is observed or how it is built — rewrite how into the observation.
- **Background restating the parent.** Link the parent.
- **Ambiguity words** — *robust*, *clean*, *appropriate* — that make a criterion longer and less binary.
- **More than a handful of criteria.** Past that, it is a plan wearing an item's clothes; split it. Test: count them — past a handful, it is a plan; split it.

## Cost

Hours to days. Vague criteria are built as slack rather than absorbed.

## Moves

Rewrite ambiguity into binary questions; a criterion that can be a test is written as the test. Retire the item as done, done differently, or dropped, naming which.
