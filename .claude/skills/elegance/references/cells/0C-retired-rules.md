# 0C · Retired rules

Tier 0 [**Principles**](../scope.md) · [**Past**](../time.md) · below [1C field history](1C-field-history.md) · across [0A proposal](0A-proposal.md), [0B rules](0B-rules.md).

## Example

A rule the organization once lived by, and the handbook version that carried it.

## Location

**Archive**, in the [location key](../grid.md#location-key).

## Clear when

The retired rule is kept as it was, with one line saying why it was retired and what replaced it; version control is the rung, an authored note assertion.

## Excess

- **The old text copied into the archive note.** Version control holds it; the note links the commit. Test: check whether git holds the old text — it does; link the commit and drop the copy.
- **A retirement rationale longer than the rule.** Why, and what replaced it, one line.
- **Citations of the retired rule left in the living set.** The archive is the only place the old shape survives; every other citation is rewritten to its replacement. Test: grep the living set for the retired rule — every hit outside the archive rewrites to its replacement.

## Cost

Low, unless still quoted — then residue pulls practice back.

## Moves

Never rewrite archived text; correct only the reason or the replacement note. At retirement, one line pointing at the replacement, connected to the commit. The alteration that matters is in the living set.
