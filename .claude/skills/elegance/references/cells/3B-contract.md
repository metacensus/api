# 3B · Contract

Tier 3 [**System**](../scope.md) · [**Current**](../time.md) · above [2B identity](2B-identity.md) · below [4B surface](4B-surface.md) · across [3A design](3A-design.md), [3C release](3C-release.md).

## Example

The contract the system exposes, and how to run it and contribute to it.

## Location

**Project API/Docs**, in the [location key](../grid.md#location-key).

## Clear when

The contract exposed equals the contract implemented, both sides of every seam agree, and a newcomer can run and contribute from the readme without asking; a gate where the contract is generated or typed, docs at review or assertion.

## Excess

- **A readme that describes the code.** The readme says what the system is, what it refuses, and how to run it. Architecture belongs in [3A](3A-design.md), module surfaces in [4B](4B-surface.md); the readme links down and restates neither. Test: for each line ask whether it says what the system is, refuses, or how to run — anything about how it is built links down instead.
- **Prose beside a generated contract.** The schema is the contract. A sentence about a field that the field's type and name already say is a second copy. Test: cover the sentence and read the field's name and type — if they say it, the sentence is a copy.
- **A contributor guide that restates the gate.** Name the command; the gate's own output says what it checks.
- **A one-way door explained more than once.** Explained at the door, once, where the choice was made.
- **"What this is not" grown into an essay.** The refused concerns are a list, each one line.

## Cost

The most dangerous cell. A semantic collision on an identical signature executes rather than errors, and no instrument sees it.

## Moves

Generate the contract from the implementation or the reverse so they cannot disagree. Rewrite the docs in the same change that moves the surface. Connect down to [4B](4B-surface.md) rather than restate it, and record a delta rather than describe the surface again.
