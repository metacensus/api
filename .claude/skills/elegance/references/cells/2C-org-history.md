# 2C · Org history

Tier 2 [**Organization**](../scope.md) · [**Past**](../time.md) · above [1C field history](1C-field-history.md) · below [3C release](3C-release.md) · across [2A roadmap](2A-roadmap.md), [2B identity](2B-identity.md).

## Example

Earlier versions of the vision, and the annual reports that show how it moved.

## Location

**Archive**, in the [location key](../grid.md#location-key).

## Clear when

Preserved unedited since it was superseded, findable when history is the question, and never cited as current; version control is the rung.

## Excess

- **A superseded vision or annual report copied into the archive where version control already holds it.** Extend only where the record system cannot be read when history is the question.
- **An old vision annotated into a new one.** Superseded text stays as it was; the new vision is [1A](1A-vision.md).

## Cost

Low. Residue if an old vision is mistaken for the present one.

## Moves

Never rewrite. Connect to version control rather than copy from it.
